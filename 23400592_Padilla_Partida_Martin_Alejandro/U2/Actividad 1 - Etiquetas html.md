| Etiqueta HTML | ¿Para qué sirve?                                                      | Sintaxis de ejemplo                        |
| ------------- | --------------------------------------------------------------------- | ------------------------------------------ |
| `<html>`      | Define el inicio y fin de un documento HTML.                          | `<html> ... </html>`                       |
| `<head>`      | Contiene información y configuraciones de la página.                  | `<head> ... </head>`                       |
| `<title>`     | Define el título que aparece en la pestaña del navegador.             | `<title>Mi página</title>`                 |
| `<body>`      | Contiene todo el contenido visible de la página.                      | `<body> ... </body>`                       |
| `<h1>`        | Crea un encabezado principal.                                         | `<h1>Título principal</h1>`                |
| `<h2>`        | Crea un subtítulo de segundo nivel.                                   | `<h2>Subtítulo</h2>`                       |
| `<p>`         | Define un párrafo de texto.                                           | `<p>Este es un párrafo.</p>`               |
| `<br>`        | Inserta un salto de línea.                                            | `Hola<br>Adiós`                            |
| `<hr>`        | Inserta una línea horizontal o separador.                             | `<hr>`                                     |
| `<a>`         | Crea un enlace hacia otra página o recurso.                           | `<a href="https://google.com">Google</a>`  |
| `<img>`       | Inserta una imagen.                                                   | `<img src="foto.jpg" alt="Foto">`          |
| `<ul>`        | Crea una lista sin orden numérico.                                    | `<ul><li>Elemento</li></ul>`               |
| `<ol>`        | Crea una lista ordenada con números.                                  | `<ol><li>Elemento</li></ol>`               |
| `<li>`        | Define un elemento dentro de una lista.                               | `<li>Elemento</li>`                        |
| `<div>`       | Agrupa elementos para organizar la estructura de la página.           | `<div>Contenido</div>`                     |
| `<span>`      | Permite agrupar o modificar una parte pequeña del texto.              | `<span>Texto</span>`                       |
| `<strong>`    | Indica texto de gran importancia y normalmente lo muestra en negrita. | `<strong>Importante</strong>`              |
| `<em>`        | Da énfasis al texto y normalmente lo muestra en cursiva.              | `<em>Énfasis</em>`                         |
| `<table>`     | Crea una tabla.                                                       | `<table> ... </table>`                     |
| `<tr>`        | Define una fila de una tabla.                                         | `<tr> ... </tr>`                           |
| `<th>`        | Define una celda de encabezado en una tabla.                          | `<th>Nombre</th>`                          |
| `<td>`        | Define una celda de datos en una tabla.                               | `<td>Juan</td>`                            |
| `<form>`      | Crea un formulario para introducir o enviar datos.                    | `<form> ... </form>`                       |
| `<label>`     | Define una etiqueta para un campo de formulario.                      | `<label>Nombre:</label>`                   |
| `<input>`     | Crea un campo de entrada de datos.                                    | `<input type="text">`                      |
| `<button>`    | Crea un botón interactivo.                                            | `<button>Enviar</button>`                  |
| `<textarea>`  | Crea un área para introducir texto largo.                             | `<textarea></textarea>`                    |
| `<select>`    | Crea una lista desplegable.                                           | `<select><option>Opción</option></select>` |
| `<option>`    | Define una opción dentro de una lista desplegable.                    | `<option>Opción 1</option>`                |
| `<header>`    | Define la cabecera de una página o sección.                           | `<header>Encabezado</header>`              |
| `<nav>`       | Contiene enlaces de navegación.                                       | `<nav><a href="#">Inicio</a></nav>`        |
| `<main>`      | Contiene el contenido principal de la página.                         | `<main>Contenido principal</main>`         |
| `<section>`   | Define una sección dentro del documento.                              | `<section>Información</section>`           |
| `<article>`   | Representa un contenido independiente, como un artículo.              | `<article>Mi artículo</article>`           |
| `<footer>`    | Define el pie de página o sección.                                    | `<footer>© 2026</footer>`                  |
